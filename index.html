Player Registration
Register players and set the number of courts. Players are split as evenly as possible across courts for Set 1.
How it works:
Set 1: Players split randomly and evenly across available courts (balance player). Each court runs a round robin — each player partners with every other player on their court once.
Set 2 & 3: Top 4 from each court → Court 1. Bottom 4 from each court → Court 2. Fresh round robin on new courts.
Scoring: Match max = 15 pts. Each player receives half their team's score (e.g. 15–12: winners get 7.5 pts each, losers get 6.0 pts each).
Point Calculation Method: 15 points sudden death, no deuce.
